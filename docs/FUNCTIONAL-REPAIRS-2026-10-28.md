## 迁移与接口约定

- 旧明文、旧下标 Keychain 引用都能读取；下次成功保存迁移到新批次。账号/WiFi ID 和关联顺序不变。秘密条目已丢失时明确报错，迁移无法恢复不存在的密码。
- Enterprise/WEP 的 JS 规则和原生 profile 在读取/同步时关闭应用内自动连接，其余认证字段保留；系统已保存网络由系统设置连接。
- StorageAdapter 签名不变，get 的 null 只表示键不存在；读取/解析错误由异常返回。已有非法配置不自动覆盖。
- NetworkDetector.getNetworkStatus 增加可选 `{ fresh: true }`；适配器提供可选 invalidateCache。原有默认调用保持兼容。
- resolveNetworkInfo 可接收实际门户；AuthService.logout 可接收显式门户并优先使用。桌面 auth_session 独立存储，不含额外密码、不改变账号结构。
- 桌面 config.set/reset、settings.update 及独立自启操作返回 `{ config, applied, error? }`。前端采用返回配置，applied=false 显示失败，持久化失败拒绝 Promise。
