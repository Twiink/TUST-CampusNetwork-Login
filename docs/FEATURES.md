# NetMate 功能说明

适用范围：Windows、macOS、Linux 桌面端及 Android。iOS 另行规划。

## 配置和账号

在“配置设置/设置”的账号或 WiFi 卡片点击“编辑”。账号支持用户名、服务器、运营商与密码；WiFi 支持 SSID、密码、优先级、认证要求、每网络自动连接及关联账号的上下顺序。保存保留原 ID，账号关联不会因为修改密码而丢失。密码留空保留原密码，WiFi 的“清除 WiFi 密码”才会明确清空。

附近 WiFi 卡片点击“扫描附近 WiFi”刷新，显示信号、安全类型和已保存标记。选择未保存网络会预填新增表单；已保存网络直接进入编辑。权限拒绝、定位关闭、扫描超时或系统限流均会显示重试说明，空结果仍可手动填写。

配置通过串行队列保存，revision 递增。桌面显示保存和生效状态；Android 显示保存及同步阶段，原生层拒绝旧 revision，失败后提供重试入口。

## 登录、注销和网络状态

手动登录、托盘登录和自动认证都按当前 WiFi 的有效关联账号顺序尝试；没有有效关联时使用当前账号。一个账号异常或超时后继续下一个。校园网、移动、联通、电信四种选项使用一致的协议样例。

点击“断开连接”会先持久暂停自动认证，再串行注销。注销失败也保持暂停，退出应用或重启后仍保留；“恢复自动认证”或再次手动登录可解除。WiFi 系统关联规则独立于认证暂停。

Android 首页区分 WiFi 已关联、门户认证和互联网可达，统一消费 AppContext 快照。前台与后台共用原生串行认证引擎，门户及联网探测绑定实际 WiFi Network。注销使用最近成功认证的服务器。

## 连接与重连

WiFi 卡片提供自动连接开关和手动连接。断线后依次重试原网络及备用网络，全部失败后调度下一轮；冷却为零仍至少等待 5 秒。关闭自动重连、关闭 WiFi 或停止服务会取消后续任务。

Android 展示连接阶段、目标、次数、倒计时及失败清单。Android 10+ 会进入系统授权/选择流程，应用等待实际目标 SSID 和地址确认连接结果。系统或厂商可能拒绝网络建议。

Windows 支持首次连接开放和个人密码网络，profile 仅写入当前系统用户。企业认证沿用系统配置。macOS 网络字段由 Darwin 原生结构解析，字段缺失/非法时逐项回退。

## 日志与更新

Android 日志页支持 debug/info/success/warn/error 筛选、分页、清空和系统分享导出。JS、前台和后台日志统一保存，保留最近 7 天，单文件上限 5 MB，最多 3 个历史文件；重启可继续查看。

Android 设置页“应用更新”支持手动检查、应用内进度、取消/重试，重启后恢复下载状态。下载完成校验包名、版本和签名，通过后提供安装入口；缺少安装权限时引导到系统授权页，返回后继续安装。系统安装确认由用户操作。

通用包 versionCode 为基础版本码 × 10，ABI 分包额外加 1–4。发布时递增基础版本码，下版通用包版本码大于上一版所有 ABI 分包。测试 APK 使用独立应用 ID 和测试签名，不用于正式分发。

## 验证范围

自动测试使用模拟账号、受控门户和无线硬件边界，验证实际 UI、IPC/原生桥接、调度和存储。真实校园网可达性、运营商开通情况、厂商后台保活及实际无线驱动行为需要对应设备和环境验证，测试通过不代表这些外部条件已验收。
