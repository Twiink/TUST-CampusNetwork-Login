## 布局与主题

2026-10-30 起，四端改为用户确认的「天空主题」。视觉依据为 `design/netmate-sky.html` 原型（`design/app.css`、`design/app.js`，日夜开关以 `design/toggle-lab.html` 为准）与 `design/PORT-SPEC.md` 移植规格；上表中的原 React/RN 页面改为行为与信息参考。功能、命令、保存串行化、首页签名、倒计时只更新文字、日志分页与 Android 软件绘制保持不变。

- 侧栏：天空蓝渐变（白天 `#2a68ad → #4a90d9`，黑夜 `#070d1c → #15213b`），白天两朵静态云，黑夜静态星点；底部为日夜开关与「白天 / 黑夜」说明。手机为顶栏加三项底部导航。
- 日夜开关：2026-10-30 按用户确认的 `design/toggle-lab.html` 重画，结合 Elsht666/Button「按钮-全月」与 JamesnetGroup/themeswitch。侧栏尺寸为 200×90 设计稿的 0.44 倍（约 88×40）。滑块白天是太阳，入夜滑到右侧变成满月，环形山在切换后半段出现；滑块外围三层半透明光环；底部两层九圆云入夜时向两侧散开并淡出；星星入夜时上浮淡入。切换 0.55 s，滑块使用 cubic-bezier(0.68,-0.1,0.265,1.2) 回弹，云散开使用 EaseInOut。窗口显示并激活时光环呼吸、云轻微摆动、亮星闪烁；窗口最小化、关闭到托盘或在后台时停在静止帧并停止计时器；系统关闭动画时直接显示终态。
- 运行状态：天空面板（可访问名称「网络连接状态」）按状态显示晴（已联网）、多云与尝试进度（重连中）、阴雨（未连接），黑夜以带环形山的月亮替代太阳；五格指标条，含心跳检测与倒计时；「网络详情」与「切换 WiFi」两列等宽，WiFi 行的标签列与操作列固定宽度对齐。
- 配置设置、运行日志、关于：分组标题加卡片；运营商、导出范围、导出格式改为自绘下拉框，日志页下拉框向上展开。

### 各平台降级与差异

| 平台    | 与原型的差异                                                                                                                                                                                                                                                                                                                                                                                                     |
| ------- | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GTK     | Cairo 无模糊，阴影以多层半透明图形近似；窗口激活时云飘移、星星闪烁（已实现）；下拉框使用 `gtk::DropDown` 加 CSS。                                                                                                                                                                                                                                                                                                |
| Win32   | 开关在 32 位 DIB 上用软件抗锯齿绘制，投影为五层半透明胶囊叠加；窗口激活时光环呼吸、云摆动、亮星闪烁，失去激活、最小化或隐藏到托盘时停在静止帧并 `KillTimer`；系统关闭客户区动画时直接显示终态。卡片无投影；下拉列表为系统列表框（直角），箭头上下翻转而非旋转；关于页名称用 700 字重代替 800；日志工具栏的「来源」「最近小时」可访问名称来自不绘制的前置标签。                                                   |
| AppKit  | 开关用 CoreGraphics 绘制；窗口为主窗口或关键窗口、未最小化、未被遮挡且应用未隐藏时播放动效，否则停在静止帧并停止计时器；「减少动态效果」开启时直接显示终态。卡片无投影；下拉列表为系统 `NSMenu`，只改文字颜色；日志页底部下拉框外框为 42（含 3px 展开外圈），可见面高 36。                                                                                                                                       |
| Android | 开关由一个 `TimeAnimator` 驱动，只在 Activity 处于 resumed 且窗口有焦点时播放动效，`onStop` 时立即停在静止帧；系统关闭动画时直接显示终态。软件绘制，开关投影为叠加半透明胶囊，卡片只用描边；展开的下拉框以 1.5dp 强调色描边代替外圈。手机没有关于页（更新检查在配置页）。日志页底部按钮可见文字为「导出」「清空」，可访问名称仍为「导出日志」「清空日志」。后台快照没有下次心跳时间，心跳格不显示「Ns 后检测」。 |

下拉框名称：四端的标题与可访问名称统一为「运营商」「导出范围」「格式」（原「服务商」「导出格式」已更名）。CI 冒烟测试不依赖这些名称。

桌面没有保存选择时采用系统主题；Android 默认黑夜。主题偏好归界面所有，与后台网络配置分离。GTK/Win32 使用 `appearance-v1`，AppKit 使用应用 UserDefaults，Android 使用 `netmate_native_ui_v1`。主题切换直接更新视图；Android 保持 Activity 和 Binder 连接，四端保留当前页面及未提交的表单内容。

## 验证与交付状态

2026-10-30 的天空主题移植（含同日重画的日夜开关、关于页与日志页布局）只做了源码检查：`rustfmt --edition 2024 --check`（`linux.rs`、`windows.rs`、`windows/appearance.rs` 通过）、Swift 与 Kotlin 括号平衡、Android XML 的 `xmllint --noout`（通过）。本机没有 `swiftc`，未执行 Swift 解析；GTK CSS 未经 GTK 解析。新界面的编译、clippy、截图、日夜对照、窗口激活时动效持续、后台与最小化时动效停止及对应 CPU 占用、UI 自动化均**待验证**。下文 CI 截图与测试证据属于天空主题之前的页面，不作为当前源码的验收结果。

本机仅执行源码检查，不构建、启动界面或执行 E2E。Rust 由 rustfmt 解析；Swift/Kotlin 使用独立语法解析器；Android XML 和工作流单独校验。平台编译、截图与原生 UI 自动化在 GitHub Actions 执行。

CI 源码已加入两套主题、四个桌面页面/三个手机页面的截图，以及导航、主题持久化和输入保留回归。Linux/Windows 截图进入 `dist-native/visual`；macOS 截图进入 XCTest 的 `macos-ui.xcresult`；Android 截图由 instrumentation 导出。[CI 40882814262](https://github.com/Twiink/TUST-CampusNetwork-Login/actions/runs/40882814262) 已生成四平台主题截图，并通过导航、主题持久化、输入保留与 100 次生命周期测试。截图可在对应 `native-*` artifact 中查看。自动化通过不代表系统字体、缩放和所有实际屏幕已逐项人工验收。

验收时在相同主题和窗口尺寸下对照原页面，检查导航层级、卡片排列、长 SSID/账号/IPv6、空状态、错误、系统缩放与手机大字体。完整进程树内存、启动和包体积与对应构建一起复测；以发布流水线的源码摘要及产物为准。仓库内早期本机安装包属于界面还原前构建，不用于发布。
