# 原生界面的视觉约定

适用版本：NetMate 2.0 原生替代分支，2026-10-29。用户要求保持原页面外观及白天、黑夜主题。原 React 页面和样式是视觉依据；原生实现使用系统控件及绘图，不引入浏览器运行时。

## 布局与主题

2026-10-31 起，四端改为用户确认的「校园一卡通」样式，视觉依据为 `design/netmate-card.html`，Linux（`apps/native-ui/src/linux.rs`、`netmate.css`）为各端移植参照；此前的天空主题（`design/netmate-sky.html`）与原 React/RN 页面改为行为与信息参考。功能、命令、保存串行化、首页签名、倒计时只更新文字、日志分页、Android 软件绘制与 CI 可访问名称保持不变。

- 侧栏（手机为顶栏与三项底部导航）：深色石墨底（白天 `#1d2329`，黑夜 `#0d1013`），顶部为金色芯片小卡加「NetMate / 天津科技大学校园网」，导航选中项为深一级底色加金色图标，底部为日夜开关与说明。
- 日夜开关：四端按 CodePen linxiang-webcraft/pvbvLBN 还原，原版保存在 `design/toggle-pen.html`，各端按 Linux `draw_toggle` 逐项移植。按原版 em 单位以每 em 16px（dp/pt）绘制，开关 90×40：白天背景 `#3d7eae`、黑夜 `#1d1f2c`；金色太阳 `#ecca2f` 外围三层 0.625em 的 10% 白色光环；入夜太阳滑到右侧，灰色月面 `#c4c9d1` 从右侧滑入盖住太阳，带三个环形山；白天两层云在底部，入夜下沉 3em；七颗四角星入夜从上方落下。所有过渡为 0.3 s CSS `ease`，中途反向从当前值重新开始；鼠标悬停时太阳向中间偏移 0.187em。只在过渡期间运行帧时钟或计时器，没有常驻动效；系统关闭动画时直接显示终态。
- 运行状态：首页主体是一张 440×276 的校园卡（可访问名称仍为「网络连接状态」），左上为发卡方与当前 WiFi，金色芯片，状态灯（正常、警告、失败、未配置四色）加状态大字，卡号由账号按四位分组，底部为运营商、关联账户、WiFi 规则等字段；多账号时卡后叠一到两张卡背。未连接 WiFi、未配置规则或账号时卡面变为虚线空卡。重连时卡底磁条即尝试进度。卡旁（手机在卡下）为标题、说明、描边标签与操作按钮；再下为五格指标条与「网络详情」「切换 WiFi」，WiFi 行以两位优先级序号开头。
- 配置设置：账号行带小卡缩略图（使用中为卡面渐变），WiFi 规则行以金色优先级序号开头；通用设置与通知设置为不带卡片的分组列表。
- 运行日志与关于：日志为四列行、细线分隔，级别筛选为分段按钮；关于页左侧为版本卡（手机没有关于页）。

### 各平台降级与差异

| 平台    | 与原型的差异                                                                                                                                                                                                                                                                                                                                                                                                                                                    |
| ------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| GTK     | Cairo 无模糊，开关与卡面阴影以多层半透明图形近似；卡背、芯片和磁条用 Overlay 与子控件拼出；描边标签用 FlowBox 换行；下拉框使用 `gtk::DropDown` 加 CSS，开关使用 `gtk::Switch`。                                                                                                                                                                                                                                                                                 |
| Win32   | 开关在 32 位 DIB 上用距离场抗锯齿软件合成，裁剪栈模拟 Cairo，阴影为六层半透明叠加，星星为展平的三次曲线加 4×4 超采样；16 ms 计时器只在过渡中运行，系统关闭动画时直接显示终态。卡面无投影，圆角渐变用区域裁剪（无抗锯齿）；1.5px 墨色线在 96 DPI 下为 2px，虚线为 1px `PS_DASH`；无字距，等宽字体用 Consolas；设置开关为系统复选框，数字为编辑框；普通按钮无悬停态；日志 ListView 无行间细线与等宽字体；关于页链接为只读编辑框；窄窗口时内容横向压缩。           |
| AppKit  | 开关用 CoreGraphics 在翻转坐标中绘制，六层偶奇填充近似模糊阴影，悬停用 tracking area；「减少动态效果」开启或窗口不可见时直接显示终态。设置开关用 `NSSwitch`；首页描边标签纵向排列而非换行；卡组视图高 314（比 Linux 多 16，容纳卡面投影）；关于页链接为金色文字；日志详情的级别标签只描边；下拉列表为系统 `NSMenu`。                                                                                                                                            |
| Android | 开关在软件 Canvas 上绘制，`postOnAnimation` 只在过渡中排帧，`onStop` 与脱离窗口时立即停在终态，系统动画缩放为 0 时直接显示终态；悬停偏移只响应鼠标，键盘焦点显示金色外圈。卡组按 456×298 设计、等比缩放到屏宽，小字保持最小可读字号；指标条按 3+2 换行；当前账号显示「使用中」文字。手机没有关于页（更新检查在配置页）。日志页底部按钮可见文字为「导出」「清空」，可访问名称仍为「导出日志」「清空日志」。后台快照没有下次心跳时间，心跳格不显示「Ns 后检测」。 |

下拉框名称：四端的标题与可访问名称统一为「运营商」「导出范围」「格式」（原「服务商」「导出格式」已更名）。CI 冒烟测试不依赖这些名称。

桌面没有保存选择时采用系统主题；Android 默认黑夜。主题偏好归界面所有，与后台网络配置分离。GTK/Win32 使用 `appearance-v1`，AppKit 使用应用 UserDefaults，Android 使用 `netmate_native_ui_v1`。主题切换直接更新视图；Android 保持 Activity 和 Binder 连接，四端保留当前页面及未提交的表单内容。

## 验证与交付状态

2026-10-30 的天空主题移植（含同日重画的日夜开关、关于页与日志页布局）只做了源码检查：`rustfmt --edition 2024 --check`（`linux.rs`、`windows.rs`、`windows/appearance.rs` 通过）、Swift 与 Kotlin 括号平衡、Android XML 的 `xmllint --noout`（通过）。本机没有 `swiftc`，未执行 Swift 解析；GTK CSS 未经 GTK 解析。新界面的编译、clippy、截图、日夜对照、窗口激活时动效持续、后台与最小化时动效停止及对应 CPU 占用、UI 自动化均**待验证**。下文 CI 截图与测试证据属于天空主题之前的页面，不作为当前源码的验收结果。

2026-10-31 的 Linux 校园一卡通移植只做了源码检查：`rustfmt --edition 2024 --check apps/native-ui/src/linux.rs` 通过，`netmate.css` 的括号配对和 `var()` 引用已用脚本核对；GTK CSS 未经 GTK 解析。

2026-11-01 Windows、macOS、Android 跟进校园一卡通样式并换用 CodePen 日夜开关，同样只做了源码检查：`rustfmt --edition 2024 --check`（`windows.rs`、`windows/appearance.rs`）通过；Swift（`main.swift`、`Appearance.swift`）与 Kotlin（`MainActivity.kt`、`NetMateAppearance.kt`）括号配对脚本核对通过；Android XML `xmllint --noout` 通过。本机没有 `swiftc`，未执行 Swift 解析。四端编译、clippy、日夜截图、各首页状态的实际渲染、开关动效与停止、UI 自动化（AT-SPI、UIA、XCUITest、instrumentation）与性能数字均**待验证**。

本机仅执行源码检查，不构建、启动界面或执行 E2E。Rust 由 rustfmt 解析；Swift/Kotlin 使用独立语法解析器；Android XML 和工作流单独校验。平台编译、截图与原生 UI 自动化在 GitHub Actions 执行。

CI 源码已加入两套主题、四个桌面页面/三个手机页面的截图，以及导航、主题持久化和输入保留回归。Linux/Windows 截图进入 `dist-native/visual`；macOS 截图进入 XCTest 的 `macos-ui.xcresult`；Android 截图由 instrumentation 导出。[CI 40882814262](https://github.com/Twiink/TUST-CampusNetwork-Login/actions/runs/40882814262) 已生成四平台主题截图，并通过导航、主题持久化、输入保留与 100 次生命周期测试。截图可在对应 `native-*` artifact 中查看。自动化通过不代表系统字体、缩放和所有实际屏幕已逐项人工验收。

验收时在相同主题和窗口尺寸下对照原页面，检查导航层级、卡片排列、长 SSID/账号/IPv6、空状态、错误、系统缩放与手机大字体。完整进程树内存、启动和包体积与对应构建一起复测；以发布流水线的源码摘要及产物为准。仓库内早期本机安装包属于界面还原前构建，不用于发布。
