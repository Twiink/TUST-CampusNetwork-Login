## 恢复流程验收

| 场景                         | 已验证结果                                                                                                      | 主要证据                                                                                                  |
| ---------------------------- | --------------------------------------------------------------------------------------------------------------- | --------------------------------------------------------------------------------------------------------- |
| 校园网、移动、联通、电信请求 | 账号后缀、指定门户、WiFi 地址和注销协议保持一致；账号失败按关联顺序继续。                                       | shared AuthService/auth-protocol 测试、desktop auth-routing、Android ReleaseHardening/FragmentedTransport |
| 门户成功、持续无外网         | 保留已认证状态，按间隔达到阈值后尝试备用；不重复提交成功认证，不提前报告网络恢复。                              | recovery-functional、FunctionalCompletionTest                                                             |
| 自有热点失去外网             | WiFi 仍关联也进入联网确认和候选切换，不发送门户请求。                                                           | 同上                                                                                                      |
| 同名网络、相同权重           | 使用配置 ID、安全类型和可选 BSSID 匹配；相同权重保留原配置顺序。关闭某条规则不阻止其他自动候选。                | reconnect-flow、WifiReconnectPolicy、WifiConnectionIdentity、FunctionalCompletionTest                     |
| 每个候选失败                 | 关联/认证按每 WiFi 最大次数执行；达到联网确认阈值后进入下一候选。全部失败保留逐网原因，冷却 0 仍至少等待 5 秒。 | reconnect-flow、recovery-functional、FunctionalCompletionTest                                             |
| 启动和运行时四种组合         | 启动开关控制首次选择，断线开关控制之后丢失关联；仅启动连接失败后没有自动循环，仍保留失败阶段及立即重试入口。    | 两端编排回归                                                                                              |
| 主动注销和手动切换           | 注销持久暂停自动认证；手动连接立即使旧任务失效，物理命令串行，旧结果不覆盖当前状态。                            | auth-session、两端恢复回归、Android release regression                                                    |
| 关闭无线开关或停止恢复       | 发布取消和原因，取消冷却；正在执行的认证响应或阶段不能把界面恢复为连接中。                                      | recovery-functional、FunctionalCompletionTest                                                             |
| 隐藏窗口、首页重新挂载       | 后台服务继续工作，重新打开可获取恢复阶段、失败清单和下次重试时间。                                              | recovery-functional、既有隐藏窗口普通回归；实际窗口生命周期 E2E 待 CI                                     |

Android 使用应用自己的网络建议选择候选，失败时撤销该目标，成功时保留成功目标；提交建议后等待真实网络身份与地址，联网确认通过后才报告恢复。系统未选择目标时显示等待、超时及系统 WiFi 入口。普通应用最终接入点的选择遵循 [Android 官方网络建议接口](https://developer.android.com/develop/connectivity/wifi/wifi-suggest)。实际系统授权和接入结果待设备验证。
