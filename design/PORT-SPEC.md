# NetMate 天空主题：原生移植规格

用户已确认的原型在 `design/` 下：`netmate-sky.html`、`app.css`（令牌与布局）、`toggle.css`（日夜按钮）、`app.js`（页面结构与交互）。以原型为视觉依据。本规格只列出移植时必须遵守的内容；颜色、尺寸、圆角以原型 CSS 为准。

## 1. 不能改变的东西

- 功能、命令、数据流、保存逻辑不变。只改外观和布局代码。
- 性能优化保留：
  - 首页签名（`home_signature` 或同类）用于避免重建。
  - 倒计时每秒只更新文字。
  - 日志分页和虚拟列表。
  - Android 软件绘制（`hardwareAccelerated=false`）。
  - 保存操作串行化。
- 后台时不能有持续动画或定时重绘。原型里一直在动的部分（云飘移、星星闪烁、太阳呼吸）在窗口显示且处于激活状态时持续播放（用户 2026-10-30 确认）；窗口最小化、关闭到托盘或切到后台时停在静止帧，停止帧时钟或计时器。
- CI 依赖的可访问名称保持不变：`网络连接状态`、`账号配置`、`搜索全部保留历史`、`检查更新`、`搜索 / 刷新`、`切换至白天模式`、`切换至黑夜模式`。现有代码里其他可访问名称和测试 ID（Android `res/values/ids.xml`、`NativeUiTest.kt`）也保留。
- 工作区里已有的未提交改动是用户的工作，在其基础上修改，不要还原、不要 `git checkout`/`reset`。
- 本机不构建、不跑 E2E、不启动模拟器。允许 `rustfmt --check`/`rustfmt`、`xmllint --noout`、纯语法解析。不要把编译检查（`cargo check`、`gradle`、`swift build`）当静态检查用。

## 2. 令牌

白天：ground `#eaf3fc`、surface `#ffffff`、surface-2 `#f2f7fc`、line `#d9e6f2`、text `#0f2a44`、text-2 `#4f6a84`、accent `#2370c0`、accent-soft `#e1eefb`、ok `#17865c`、warn `#a8650a`、bad `#c93838`。侧栏渐变 `#2a68ad → #4a90d9`（上到下）。

黑夜：ground `#0a1222`、surface `#111c31`、surface-2 `#16233b`、line `#22324d`、text `#e4ebf5`、text-2 `#94a6bf`、accent `#f0d98a`（月光金）、on-accent `#1a1606`、ok `#5fd39f`、warn `#f2b45a`、bad `#ff7b7b`。侧栏渐变 `#070d1c → #15213b`。

天空面板渐变（160°）：

- 白天：晴 `#3d84d0/#6fb0ee/#a9d3f7`，多云 `#6b8fb6/#9db8d4/#c9d8e6`，阴雨 `#56606f/#7d8795/#a5adb8`。
- 黑夜：晴 `#070d1c/#111a30/#1f3156`，多云 `#141b2c/#253149/#34415a`，阴雨 `#1d1416/#3a2427/#4b3033`。

卡片圆角 14，天空面板 16，按钮/输入框 9，徽标 6。卡片 1px line 描边加轻阴影（平台能做就做，做不到就只用描边）。

## 3. 日夜切换按钮（Elsht666「按钮-全月」）

设计尺寸 200×90，侧栏里按 0.44 缩放（约 88×40）；Android 顶栏同尺寸或略小。按 `toggle-lab.html` 绘制（2026-10-30 起替代 `toggle.css`）：旋钮白天是太阳、黑夜是带环形山的满月，外围三层半透明光环；底部两层云（themeswitch 的九圆云形），入夜时向两侧散开并淡出；星星（themeswitch 星图）入夜时上浮淡入。下列颜色仍适用：

- 白天：背景渐变 `#4a90d9 → #6fb0ee → #9bcbf5`（135°）；右上发光太阳（`#fff5c0/#ffd84d/#ffc107` 径向，带两层光晕）；四朵白云；左侧金色滑块（`#ffe7a0/#f0d080/#e2bf6a`，直径 86，带投影与内高光）。
- 黑夜：背景 `#070d1c → #111a30 → #1c2a48`；滑块移到右侧（translateX 110）变银色（`#e4e4e4/#c8c8c8/#b3b3b3`）；左上满月（`#fff/#fff6d9/#f2e3a8` 径向加光晕）；八颗星。
- 切换过渡 0.55 s，曲线 cubic-bezier(0.68,-0.1,0.265,1.2)（略过冲）：滑块位置、滑块颜色、背景色、太阳淡出缩小、月亮淡入放大、云淡出、星星淡入同时插值。用帧时钟/计时器驱动，结束即停。
- 悬停：整体放大到 1.07（平台不便缩放时改为描边变亮）。云飘移、星星闪烁与太阳呼吸随窗口激活状态播放，不依赖悬停。
- 系统「减少动态效果」打开时直接跳到终态。

## 4. 侧栏

- 品牌 NetMate + WiFi 图标；导航四项（运行状态、配置设置、运行日志、关于），选中项为半透明白底（黑夜为月光金淡底，文字金色）。
- 底部：日夜按钮，下方小字「白天 / 黑夜」。
- 白天时侧栏下部画两朵半透明白云（同一云形，`app.js` 里 `CLOUD` 路径；一朵 138 宽在左下，一朵 86 宽在右侧稍高处，透明度 0.3/0.22）。黑夜时云隐去，改为稀疏白色小星点。静态绘制，不动画。

## 5. 运行状态页（变化最大）

自上而下：

1. 标题「运行状态」。
2. **天空面板**（可访问名称 `网络连接状态`）：左侧文案（小字来源、大标题、说明、状态标签），右下操作按钮；右上天气插画（176×120 设计尺寸）：
   - 已联网 = 晴：太阳 + 光晕 + 一朵主云（带投影）。
   - 重连中 = 多云：太阳变淡（0.6），主云 + 后方小云；文案下方显示白色进度条（第 n / N 次）。
   - 未连接 = 阴雨：无太阳，两朵灰云，下方四道斜雨丝。
   - 黑夜：太阳换成带三处淡色环形山的月亮，云改深蓝灰（`#5d6c8c → #36425c`），阴雨时云为 `#5a5258 → #352d33`。
   - 插画是静态的，状态变化时直接换图，不加持续动画。
3. **指标条**：一张卡片里五格等宽，竖线分隔：信号强度、连接速度、频段、互联网、心跳检测（「心跳检测 · 每 N 秒」，值为状态圆点 + 正常/异常 + 灰色「Ns 后检测」）。倒计时只更新这一个文字控件。未连接时整条隐藏。手机上两列，心跳格独占最后一行。
4. **两列等宽、等高、顶对齐**：左「网络详情」（键值表，右对齐等宽数字，标题右侧刷新图标按钮）；右「切换 WiFi」（标题右侧灰字「按优先级排序」）。未连接时左列换成「心跳检测 (已暂停)」说明卡。
   - WiFi 行用固定列：图标 18 | 名称+副标题（副标题含「优先级 N · 安全类型」）| 标签列固定宽 84（校园网认证 = accent 徽标，普通热点 = 灰徽标）| 操作列固定宽 68（「切换」按钮，或当前连接显示 accent 色「✓ 当前」）。当前行 accent-soft 底色加左侧 3px accent 色条。各行标签和按钮必须上下对齐。
   - 手机：两列合成一列；WiFi 行变两行（名称/副标题在上、徽标在下，操作在右侧垂直居中）。

## 6. 下拉框

运营商选择、日志导出范围、导出格式改用自绘样式：外观同输入框（高 36、圆角 9、line 描边），文字左对齐，右侧下箭头；展开时描边 accent 加 3px accent-soft 外圈，箭头旋转 180°；弹层 surface 底、圆角 11、阴影、内边距 5，选项高约 34，选中项 accent 色加对勾。日志页底部的下拉向上展开。键盘可用（方向键、回车、Esc）。

- GTK：`gtk::DropDown`（或 `MenuButton` + `Popover` + `ListBox`）配 CSS，不要用默认样式。
- Win32：owner-draw combobox（`CBS_OWNERDRAWFIXED`），自绘按钮面和列表项。
- AppKit：`NSPopUpButton`，设为无边框并自绘外框/箭头，或使用 `NSMenu` 配自定义视图。
- Android：`Spinner` 配自定义 `ArrayAdapter` 布局与背景 drawable，弹出模式 dropdown。

保留原控件的数据绑定、事件和可访问名称（`运营商`、`导出范围`、`格式`）。

## 7. 其他页面

配置设置、运行日志、关于沿用原型结构：分组标题 + 卡片；开关为 40×24 圆角滑块（开启 accent）；步进器 −/值/+；日志工具栏（搜索框带图标、来源、最近小时步进器、筛选按钮；第二行级别分段控件 + 计数）；日志行为四列网格（时间等宽、级别彩色、来源等宽、消息）；关于页英雄卡 + 两列卡片。

## 8. 平台能力降级

- Win32 用 GDI/GDI+ 在 owner-draw 控件上绘制。允许简化：按钮可只画背景渐变、太阳/月亮、滑块和简化云星；过渡用 `SetTimer` 约 16 ms，结束即 `KillTimer`；窗口激活时的飘云可省略，但悬停描边变亮要保留。
- 任何平台做不到的效果，在 `docs/NATIVE-APPEARANCE.md` 写明降级方式。

## 9. 交付

- 每个平台只改自己的文件。
- 结束时报告：改了哪些文件、做了哪些降级、跑了哪些源码检查及结果、哪些项必须等 CI 验证（标为「待验证」）。
